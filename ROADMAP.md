# Roadmap

## 0.1 — MVP

- Repeat a local command.
- Classify stable pass, stable fail, intermittent exit, output drift, and mixed flakes.
- Emit deterministic Markdown and JSON.
- Redact obvious secrets by default.
- Compare directories of saved JSON reports.

## 0.2 — Better review artifacts

- Optional compact output samples with safe truncation.
- Machine-readable JSON schema.
- Richer compare summaries across branches or fixture sets.

## 0.3 — CI ergonomics

- GitHub Actions examples.
- Suggested retry/gate recipes for common package managers.
- Exit-code policy presets.

## Later

- Semantic output differ plugins.
- JUnit-style export.
- No hosted dashboard unless the project direction changes explicitly.
